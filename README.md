# База карточек на Flask

## Запуск

1. Создайте и активируйте виртуальное окружение:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Запустите сайт:

   ```powershell
   py app.py
   ```

Откройте в браузере <http://127.0.0.1:5000>.

Демо-доступ: `admin` / `admin123`.

Файл `database.sqlite3` создается автоматически при первом запуске. Таблицы `users` и `cards` создаются приложением.

Новые пользователи могут зарегистрироваться на странице входа. Зарегистрированные пользователи имеют доступ к разделам, карточкам и поиску, но добавлять, редактировать и удалять карточки может только пользователь `admin`. Удаление выполняется после подтверждения и полностью удаляет запись из SQLite.

Администратор может добавлять разделы через кнопку «Добавить раздел». Разделы хранятся в таблице `sections`, видны всем пользователям и автоматически появляются в форме создания карточек и предложений.

Администратор может массово загружать карточки через файл `.xlsx`. Используйте ссылку «Скачать шаблон .xlsx» на странице импорта и заполните столбцы «Раздел», «Наименование», «Краткое описание», «Описание». При ошибке хотя бы в одной строке импорт целиком отменяется, а страница показывает номера и причины некорректных строк. Максимальный размер файла — 10 МБ, количество карточек в одном файле — до 5000.

Обычные пользователи могут отправлять новые карточки через кнопку «Предложить». Предложения попадают в отдельную «Предложку», доступную только `admin`. Администратор может отредактировать, принять или отклонить предложение. При принятии карточка добавляется в общую базу.

Обычные пользователи также могут добавлять карточки в «Избранное» с помощью звездочки. Избранное хранится отдельно для каждого пользователя и доступно на отдельной странице. Администратор не использует этот раздел.

Каждый пользователь может создавать, редактировать и удалять личные «Заметки». Они хранятся в таблице `notes` с идентификатором владельца и доступны только создавшему их пользователю.

Авторизованные пользователи могут оставлять комментарии к карточкам. Комментарии хранятся в таблице `card_comments` вместе с автором и временем создания, отображаются в отдельной прокручиваемой панели и удаляются вместе с карточкой.

В приложении есть боковая навигация с разделами «Карточки», «Заметки», «Новости» и «Полезная информация» (последний раздел пока подготовлен визуально). Новости хранятся в отдельной таблице `news`; добавлять их может только `admin`, остальные пользователи имеют доступ только к просмотру.

Новостные карточки открываются во всплывающем окне с прокруткой длинного текста. Дата и время публикации отображаются на карточке. Администратор может редактировать новости после публикации.

Для описаний карточек, предложений, заметок и текста новостей доступен встроенный редактор форматирования: жирный, курсив, подчеркивание, нумерованные и маркированные списки, ссылки, цвет текста и цвет выделения. Форматирование сохраняется в SQLite в безопасном очищенном HTML-виде.

При первом запуске создаются начальные разделы:

- Криптография
- Ошибки при отправке
- Ошибки при распаковке
- Ошибки на Hab

Если база была создана в предыдущей версии, приложение автоматически добавит ей поле раздела. Существующие карточки будут отнесены к разделу «Криптография».
