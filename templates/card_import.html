Загрузить карточки из Excel

Выберите файл .xlsx, заполненный по шаблону. Максимальный размер — 10 МБ.

Формат файла

В первой строке должны быть столбцы: Раздел, Наименование, Краткое описание, Описание.

Каждая следующая строка — одна карточка. Раздел должен уже существовать. Если хотя бы одна строка содержит ошибку, карточки из файла не добавляются.
